# Demo

Thư mục làm việc cho kịch bản và tài nguyên demo. File nộp cuối `demo-slides.pdf` đặt tại thư mục gốc repository.

## Sáu slide bắt buộc

1. User & Job.
2. Vì sao chọn tính năng.
3. Giải pháp và live demo: một case chuẩn, một case khó.
4. Kết quả eval so với quality bar.
5. User thật nói gì và thay đổi đã làm.
6. Nếu có thêm một tuần.

Chuẩn bị thêm `demo-script.md` và backup screenshot/video ngắn.
