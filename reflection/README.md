# Reflection

Mỗi thành viên tạo một file Markdown riêng, ví dụ:

```text
reflection/
├── truong-minh-hoang.md
├── thanh-vien-02.md
└── ...
```

Mỗi reflection cần nêu:

1. Vai trò và phần mình trực tiếp làm.
2. AI đã hỗ trợ như thế nào.
3. Một case fail của nhóm và bài học rút ra.
4. Cách phần mình làm liên kết với spec/eval/validation.

Mỗi thành viên phải giải thích được phần có tên mình tại CP5/CP6.
