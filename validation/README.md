# Validation

Thư mục chứa feedback log từ ít nhất 5 người ngoài nhóm.

Mỗi dòng cần có:

- Tên/vai người thử và có phải willing user từ CP1 hay không.
- Task được giao.
- Quan sát hành vi thực tế.
- Quote nguyên văn.
- Mức nghiêm trọng.
- Quyết định thay đổi/giữ nguyên và lý do.

File dự kiến: `validation/feedback-log.md`.
